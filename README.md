# 幻想魔法衣橱

微信开发者工具导入本目录后编译，从首页进入「装备属性试穿」。第一阶段支持职业切换、手动填写 12 项裸装属性、确认后显示面板与解锁装备，并按职业保存在手机本地。当前默认剑客；尚未填写时数值显示 0，表单输入框为空，完整填写后方可确认。

本阶段无需配置云环境。后续装备、宠物、OCR 和计算接入进度见 [开发计划](./装备属性预览开发计划.md)，交互规则见 [需求文档](./装备属性预览需求.md)。

使用 Node.js 20 或更新版本，在项目根目录执行以下命令运行测试，无需安装 npm 依赖。

```sh
node --test tests/*.test.js
```

## 原工程云开发示例说明

这是云开发的快速启动指引，其中演示了如何上手使用云开发的三大基础能力：

- 数据库：一个既可在小程序前端操作，也能在云函数中读写的 JSON 文档型数据库
- 文件存储：在小程序前端直接上传/下载云端文件，在云开发控制台可视化管理
- 云函数：在云端运行的代码，微信私有协议天然鉴权，开发者只需编写业务逻辑代码
