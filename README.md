# 幻想魔法衣橱

微信开发者工具导入本目录后编译，从首页进入「装备属性试穿」。先填写 12 项裸装属性，再点击装备或徽章录入。人物战斗属性按游戏排列为「最小攻击／防御、最大攻击／命中、魔攻／魔防」，基础属性为「力量／体质、敏捷／智慧、灵巧／精神」。六枚徽章从左到右为英勇、信仰、忠诚、卓越、睿智、狂野，法宝放在同一行末尾；各部位的录入与取下行为保持一致。当前支持本体、灵、灵变、指定部位变装，以及面饰灵变／霸者系列、项链龙啸系列、武器极暗黑威武和生命／魔攻／物攻名器之魂。手填属性按来源限制，优先排列力量、智慧、体质、最大生命；非戒指灵仍可手填六项基础属性及魔法攻击、攻击、防御、魔法防御、伤害抗性、魔法抗性。

灵变改为 900、1000、270、黄金、285 五档攻击／生命共十项预设，生命款同时提供对应最大生命与最大法力。戒指灵改为 3、7、9、黄金四档、每档四种共十六项预设，支持真*戒魄及嗜血／圣灵、恶魔／天使分支，切换即时替换该来源并重算。真戒魄移动速度仅展示，暂不计入总属性。原有手填灵变与戒指灵保留并显示为原有输入，明确选择新预设后才替换；重新打开不自动覆盖。武器切换为普通变装时自动填入力量、智慧各 150，其他普通变装词条保留。

启用的灵中，当前已填各项原始数值全部大于等于 285 时，自动增加最大生命 3000、移动速度 1%；鞋子灵的移动速度奖励合计 2%。空白、无效数值或任一词条低于 285 不生效。额外生命按直接生命接入现有计算，移动速度目前仅展示。奖励从原始词条动态推导，不写入原始数值，反复编辑、保存和重开不会重复累加。

玩家按装备实际词条选择“添加属性”，也可以上传截图识别回填。“查看上传图片标准”会打开当前部位的原图示例，顶部保留截图说明，支持滚动及点开放大，返回后录入内容保留。有效草稿会即时显示“与本部位留空相比”的实际提升与穿戴后总值；确认才保存，支持重开修改和按职业恢复。人物区提供录入、取下、清除：取下模式中点击部位停止计算，再次点击重新装备并恢复属性，录入词条始终保留；确认清除才删除当前职业全部装备，其他职业和裸装保持不变。裸装生命与法力自动计算。

手填与存储无需配置云环境。图片识别使用设备端 VKSession 静态 OCR，基础库配置为 2.27.0；不支持的设备可继续手填。识别来源不确定时保留数值供选择，识别结果需用户核对。真实设备识别准确率、键盘和画面仍待验收，宠物技能待规则补充。

当前确认裸装、装备、取下状态和预设时，会按职业自动保存到本机，不设置自动过期天数；这与尚待启用的“保存当前装备”整套存档按钮分开。本地数据可能被用户或系统清理，不能跨手机恢复。免注册云存档调研与建议见开发计划，本轮未配置云环境或启用云存档。

术士人物区依次为「录入装备、选择预设装备、取下装备、保存当前装备、分享、清除装备」，其余职业不显示预设入口。所有按钮等大并随窗口自适应；保存与分享目前仅保留待启用按钮，功能后续定义。预设窗口按每行四个等级列出 60～138 级（间隔 6 级），目前仅有 102 级数据。点击等级后进入九件图标确认页，点击图标用半透明浮窗查看白色自带属性和紫色炼化属性，点击「确认载入」才保存并更新面板。返回、查看和关闭不写数据。已有灵、灵变、变装、名器之魂及其他部位保留，可逐件打开修改或选择来源预设。头盔最大生命已修正为 4280，背包增加炼化生命 2000；先前载入的旧预设需要重新选择 102 级并确认载入，手动修改的存档不自动覆盖。尚无计算规则的伤害、攻击速度、最大负重、移动速度和法术暴击率保留为本体参考数值，暂不计入预览。

最新单项链复核将基础属性和 0.5 换算统一为向下取整，百分比最终输出仍四舍五入。该规则下最大／最小攻击各 108、力量 57、智慧 3722、精神 1538，已修正原 App 对这五项的进位；这些新字段目前仍是推算，待穿戴后游戏面板核验。生命保持实测 16848；在裸装属性中填写可选实测法力 13268 后，穿项链为实测 15248。校准随职业保存并绑定裸装精神，修改精神需重新填写；未校准时按整数精神 × 9.9 估算。计算规则中列有全部 17 项逐字段差值及核验状态，测试同时覆盖主面板和单件预览的全部字段。

实现状态见[开发计划](./装备属性预览开发计划.md)，交互规则见[需求文档](./装备属性预览需求.md)，数值规则见[计算规则](./装备属性计算规则.md)。

node --test tests/*.test.js

## 原工程云开发示例说明

这是云开发的快速启动指引，其中演示了如何上手使用云开发的三大基础能力：

- 数据库：一个既可在小程序前端操作，也能在云函数中读写的 JSON 文档型数据库
- 文件存储：在小程序前端直接上传/下载云端文件，在云开发控制台可视化管理
- 云函数：在云端运行的代码，微信私有协议天然鉴权，开发者只需编写业务逻辑代码
